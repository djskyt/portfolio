# 🌟 Popol — Frontend Portfolio

## 🔗 배포 링크
[portfolio-djskyt.vercel.app](https://portfolio-djskyt.vercel.app)

## 📌 소개
프론트엔드 개발자 김현진의 포트폴리오 사이트입니다.
부트캠프부터 채용 과제, 개인 프로젝트까지 성장 과정을 담았습니다.

## 🔧 Tech Stack
- **React 19**, **TypeScript**, **Vite**
- **Tailwind CSS**, Lucide Icons
- Vercel (Deploy)

## 🚀 Getting Started

### 1️⃣ Clone & Install
\```
git clone https://github.com/djskyt/portfolio
cd Portfolio
npm install
\```

### 2️⃣ Run Dev Server
\```
npm run dev
\```
➡️ http://localhost:5173 자동 실행

### 3️⃣ Build
\```
npm run build
\```
